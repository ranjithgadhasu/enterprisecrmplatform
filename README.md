# Enterprise CRM Platform

A modern, responsive, and user-friendly Customer Relationship Management (CRM) dashboard designed to manage customer relationships, sales activities, leads, and business operations efficiently.

## 🎯 Project Overview

The objective of this project is to develop a professional CRM platform that helps businesses manage their sales processes, maintain customer information, track interactions, and monitor overall business performance through an intuitive dashboard.

The application focuses on clean UI/UX, reusable components, responsive layouts, and smooth interactions across all CRM modules.

## 🚀 Core Modules & Features

### 1. Dashboard & Analytics
- Overview of key CRM performance metrics.
- Total leads, customers, deals, and revenue.
- Sales performance visualization.
- Lead conversion statistics.
- Interactive charts and reports.

### 2. Lead Management
- Create, view, edit, and delete leads.
- Track lead status and progress.
- Search, filter, and sort lead records.
- Manage lead contact information.

### 3. Sales Pipeline
- Visual representation of the sales process.
- Track deals across different sales stages.
- Monitor deal values and progress.
- Move deals between pipeline stages.

### 4. Customer Management
- Maintain detailed customer profiles.
- Store customer contact information.
- View customer details and interaction history.
- Manage customer relationships.

### 5. Task Management
- Create and manage tasks.
- Assign tasks and manage responsibilities.
- Set priority levels and deadlines.
- Track task completion status.

### 6. Activity Tracking
- Track customer interactions.
- Record calls, meetings, and emails.
- Maintain follow-up activities.
- View activity history.

### 7. Reports & Settings
- Access business performance reports.
- Review sales and lead statistics.
- Manage application preferences and settings.

## ⚙️ Installation & Setup

### Prerequisites
- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/ranjithgadhasu/enterprisecrmplatform.git
```

### 2. Navigate to the project directory

```bash
cd enterprisecrmplatform
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Create a production build

```bash
npm run build
```

## 📌 Project Scope

This is a frontend-only CRM application built using React.js and Vite.

- Uses mock data for demonstration.
- Uses browser Local Storage for frontend data persistence.
- No backend API or database integration.
- Designed to demonstrate CRM workflows and frontend functionality.
